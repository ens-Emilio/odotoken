# odotoken — Deutsch

odotoken installieren, CLI darauf zeigen lassen, Dashboard öffnen.

> Translation pending native review. The English README is authoritative.

## Installieren

Fertiges Binary unter [Releases](https://github.com/ens-Emilio/odotoken/releases/latest) oder aus dem Quellcode: `go build -o bin/odotoken ./cmd/odotoken`.

## Konfigurieren

`cp config.json.example config.json`, dann `upstream_url` je Provider setzen.

## CLI umstellen

Auf `http://127.0.0.1:8080` zeigen lassen (zum Beispiel `ANTHROPIC_BASE_URL`).

## Dashboard öffnen

`odotoken start`, dann http://127.0.0.1:8080/app/ öffnen.
