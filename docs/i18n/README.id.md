# odotoken — Bahasa Indonesia

Pasang odotoken, arahkan CLI Anda ke sana, lalu buka dasbor.

> Translation pending native review. The English README is authoritative.

## Pasang

Biner siap pakai di [Releases](https://github.com/ens-Emilio/odotoken/releases/latest), atau dari sumber: `go build -o bin/odotoken ./cmd/odotoken`.

## Konfigurasi

`cp config.json.example config.json`, lalu setel `upstream_url` tiap provider.

## Arahkan CLI

Arahkan ke `http://127.0.0.1:8080` (misalnya `ANTHROPIC_BASE_URL`).

## Buka dasbor

`odotoken start`, lalu http://127.0.0.1:8080/app/.
