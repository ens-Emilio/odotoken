# odotoken — Italiano

Installa odotoken, punta il tuo CLI su di esso e apri la dashboard.

> Translation pending native review. The English README is authoritative.

## Installare

Binario pronto in [Releases](https://github.com/ens-Emilio/odotoken/releases/latest), oppure dai sorgenti: `go build -o bin/odotoken ./cmd/odotoken`.

## Configurare

`cp config.json.example config.json`, poi imposta l'`upstream_url` di ogni provider.

## Puntare il CLI

Punta a `http://127.0.0.1:8080` (per esempio `ANTHROPIC_BASE_URL`).

## Aprire la dashboard

`odotoken start`, poi http://127.0.0.1:8080/app/.
