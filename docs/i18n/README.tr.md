# odotoken — Türkçe

odotoken'i kurun, CLI'nızı ona yönlendirin ve panoyu açın.

> Translation pending native review. The English README is authoritative.

## Kurulum

[Releases](https://github.com/ens-Emilio/odotoken/releases/latest) sayfasındaki hazır ikili dosya veya kaynaktan: `go build -o bin/odotoken ./cmd/odotoken`.

## Yapılandırma

`cp config.json.example config.json`, ardından her sağlayıcı için `upstream_url` ayarlayın.

## CLI'yi yönlendirme

`http://127.0.0.1:8080` adresini kullanın (örneğin `ANTHROPIC_BASE_URL`).

## Panoyu açma

`odotoken start`, ardından http://127.0.0.1:8080/app/.
