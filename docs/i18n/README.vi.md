# odotoken — Tiếng Việt

Cài odotoken, trỏ CLI của bạn vào nó và mở bảng điều khiển.

> Translation pending native review. The English README is authoritative.

## Cài đặt

Bản dựng sẵn tại [Releases](https://github.com/ens-Emilio/odotoken/releases/latest), hoặc từ mã nguồn: `go build -o bin/odotoken ./cmd/odotoken`.

## Cấu hình

`cp config.json.example config.json`, rồi đặt `upstream_url` cho từng provider.

## Trỏ CLI

Trỏ tới `http://127.0.0.1:8080` (ví dụ `ANTHROPIC_BASE_URL`).

## Mở bảng điều khiển

`odotoken start`, rồi mở http://127.0.0.1:8080/app/.
