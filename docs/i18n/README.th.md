# odotoken — ไทย

ติดตั้ง odotoken ชี้ CLI ของคุณมาที่นี่ แล้วเปิดแดชบอร์ด

> Translation pending native review. The English README is authoritative.

## ติดตั้ง

ไบนารีพร้อมใช้ที่ [Releases](https://github.com/ens-Emilio/odotoken/releases/latest) หรือสร้างจากซอร์ส: `go build -o bin/odotoken ./cmd/odotoken`

## กำหนดค่า

`cp config.json.example config.json` แล้วตั้ง `upstream_url` ของแต่ละ provider

## ชี้ CLI

ชี้ไปที่ `http://127.0.0.1:8080` (เช่น `ANTHROPIC_BASE_URL`)

## เปิดแดชบอร์ด

`odotoken start` แล้วเปิด http://127.0.0.1:8080/app/
